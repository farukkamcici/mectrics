# Privacy

Mectrics collects no analytics, telemetry, identifiers, or crash reports. System
metrics stay on the Mac and are stored locally only for the features the user enables.

The app does not send hardware information, usage data, metric history, or alert
settings to any server. Network access is reserved exclusively for an optional,
user-visible software update check once automatic updates are introduced.

Widget snapshots and the rolling metric history are stored locally in the app's
container or Application Support directory. CSV files are created only when the user
explicitly chooses an export location.
